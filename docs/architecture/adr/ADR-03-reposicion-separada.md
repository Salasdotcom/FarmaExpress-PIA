# ADR-03. Separación del registro, confirmación y envío de solicitudes de compra

| Campo del ADR | Contenido |
| --- | --- |
| Título | Separación del registro de necesidades de reposición, su confirmación y el envío de solicitudes de compra. |
| Estado | Aceptado. |
| Contexto | En FarmaExpress, el proceso de resurtido es reactivo. El personal de Almacén identifica productos faltantes o con bajas existencias y registra las necesidades de reposición. Posteriormente, el Responsable de farmacia revisa la información y decide qué necesidades se confirman. Con base en las necesidades confirmadas, se genera una solicitud de compra dirigida al área de Compras. No se contempla la generación automática de órdenes de compra ni una integración directa con proveedores. |
| Alternativas | **Proceso unificado:** registrar las necesidades, confirmarlas y generar la solicitud de compra mediante una sola operación. Simplifica el flujo, pero mezcla responsabilidades de diferentes usuarios y dificulta distinguir las necesidades identificadas de las aprobadas. **Proceso separado:** registrar las necesidades, confirmar o rechazar cada una y generar posteriormente la solicitud de compra con las necesidades confirmadas. Requiere más operaciones, pero permite conservar el control y la trazabilidad de cada etapa. |
| Decisión | Se propone separar el proceso en tres operaciones: RegistrarNecesidadReposicion, ConfirmarNecesidadReposicion y EnviarSolicitudDeCompra. Almacén registra las necesidades identificadas; el Responsable de farmacia revisa y confirma o rechaza las necesidades; finalmente, se genera la solicitud de compra con los productos y cantidades solicitadas que fueron confirmados. |
| Consecuencias | **Beneficios:** separación de responsabilidades, mayor control sobre las necesidades de reposición y trazabilidad de las decisiones del Responsable de farmacia. **Costos:** requiere conservar los estados de las necesidades y relacionarlas con la solicitud de compra generada. **Riesgos:** las necesidades no confirmadas no podrán incluirse en la solicitud de compra; también pueden existir retrasos si la revisión no se realiza oportunamente. **Trabajo posterior:** definir la información de la solicitud, los estados de las necesidades y el mecanismo mediante el cual se genera el documento para Compras, sin asumir una integración externa. |
| Trazabilidad | US06 (identificación de necesidades de reposición), US07 (revisión y confirmación de necesidades) y US08 (generación y envío de solicitudes de compra). |
